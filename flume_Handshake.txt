## What it is
Flume — visual flowchart / process-diagram studio SPA.
- Node kinds: start, end, process, decision, data, document, subprocess, database, manual, delay, note, parallel
- Edge kinds: sequence, message, conditional, default, association, async
- Lanes (rows/columns), undo/redo, palette, inspector, code pane, SVG export, templates
- Client-side state (Zustand-style store); no auth/DB required for core diagramming (VITE_AUTH_ENABLED=false, deploy.database=false)

## Tech stack
- React 19 + TypeScript
- TanStack React Router + TanStack Start
- Vite 8 + Tailwind CSS 4
- Nitro (preset vercel) for SSR/server build
- PGLite / Kysely / better-auth present but auth off by default
- Lucide icons, Radix UI primitives
- Package name in package.json: app-builder-workspace
